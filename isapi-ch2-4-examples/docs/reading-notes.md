# 第一部分　协议框架与快速入门（第 1~4 章）

## 第 1 章　阅读指南

**索引**：本章无二级小节，为单页导读。

**重点内容**
- 明确文档读者为基于海康设备做二次开发的**集成商 / 平台开发者**。
- 约定文档中接口描述的组织方式：先功能流程（第 5~29 章）、后接口字段定义（第 30 章），两者按功能域一一对应（如第 9 章「视频通用」对应 30.6）。

**摘要**：本章是阅读入口，说明文档面向 ISAPI 集成开发者，并提示「流程章节 + 接口章节」双层结构——集成时先在功能章节理解交互时序，再到第 30 章查具体接口的报文字段。

## 第 2 章　概览

**索引**：2.1 介绍｜2.2 适用产品｜2.3 术语和定义｜2.4 符号和缩略语｜2.5 更新说明

**重点内容**
- **ISAPI（Intelligent Security API）** 是海康威视设备统一的对外协议，基于 **HTTP 的 REST 风格**，报文主体为 XML（命名空间 `http://www.isapi.org/ver20/XMLSchema`，版本 2.0），在 URL 后加 `?format=json` 可切换为 JSON 交互。
- 协议族规模 **11000+ 接口**，覆盖摄像机、NVR、报警主机、门禁等产品线；本文档聚焦固定网络摄像机与 2 系列智能网络摄像机。
- 术语表是后续阅读的基础：IPC、NVR/DVR、SADP（设备发现）、RTSP（取流）、ISUP/EHome（推模式上联）、OTAP、HEOP（嵌入式开放平台）、ANPR（车牌识别）等。

**摘要**：本章给出 ISAPI 的定位——海康设备统一的、基于 HTTP REST 的智能安全接口协议，规定了 XML/JSON 双格式、适用产品范围，并集中定义了全书使用的术语与缩略语。

## 第 3 章　ISAPI 框架

**索引**：3.1 总览｜3.2 激活｜3.3 安全机制｜3.4 视频取流

**重点内容**
- **协议栈分工**：SADP 负责链路层设备发现与激活引导；ISAPI 负责配置/控制/事件；**RTSP（RFC 7826）** 负责实时取流与回放；ISUP/EHome 负责设备主动注册上联；另有 HCNetSDK、GB28181、ONVIF 等并存接入方式。
- **激活流程**：设备出厂未激活 → `GET /SDK/activateStatus`（**无需认证**）查询状态 → `POST /ISAPI/Security/challenge` 获取 RSA 公钥挑战 → 密码经 RSA + AES128-ECB 加密后 `PUT /ISAPI/System/activate` 完成激活。
- **安全机制**：认证采用 **HTTP Digest（RFC 7616）**；所有接口（除激活状态等少数外）都需携带认证头；支持会话保持与超时。
- **视频取流 URL 规则**：`rtsp://<host>:554/ISAPI/Streaming/channels/<ID>`，其中 **ID = 通道号 × 100 + 码流类型**（1 主码流、2 子码流、3 三码流），如 101 = 通道 1 主码流。

**摘要**：本章从架构上说明 ISAPI 与 SADP、RTSP、ISUP 等配套协议的分工，并定义了三个所有集成工作的前置环节：设备激活（RSA 挑战 + AES 加密设密）、Digest 认证安全机制、以及「通道×100+码流类型」的 RTSP 取流编址规则。

## 第 4 章　快速入门

**索引**：4.1 认证｜4.2 报文解析｜4.3 实时预览｜4.4 录像回放｜4.5 事件上报

**重点内容**
- **认证**：以 Digest 认证完成首个接口调通（典型如 `GET /ISAPI/System/deviceInfo`）。
- **报文解析**：四种承载格式——XML（默认）、JSON（`?format=json`）、二进制（`application/octet-stream`，用于抓图/升级包）、**multipart/form-data（RFC 1867）表单**（事件与图片混传，靠 `Content-Disposition` 的 name/filename 与 Content-ID 关联报文与图片）。
- **实时预览 / 录像回放**：均走 RTSP；回放 URL 带起止时间参数，下载用 `playbackURI` 返回的地址（下载需认证，URI 带 `?token=` 可免）。
- **事件上报**三种模式：**非订阅布防**（长连接 `GET /ISAPI/Event/notification/alertStream`）、**订阅布防**（`POST /ISAPI/Event/notification/subscribeEvent` 注册回调地址）、**HTTP 监听主机**（`/ISAPI/Event/notification/httpHosts`，设备主动 POST 到平台）。
- 字段标注体系：每个字段带 **ro/wo/req/opt/dep** 属性与 object/list/string/int/float/bool/enum 类型，能力集接口（URL 以 `/capabilities` 结尾）用于探测设备实际支持项。

**摘要**：本章给出最小集成路径：Digest 认证 → 按 XML/JSON/二进制/表单四种格式解析报文 → RTSP 实时预览与录像回放 → 三种事件接收方式（长连接布防、订阅回调、HTTP 监听）任选其一，并介绍了贯穿全书的字段标注（ro/req 等）与 capabilities 能力探测机制。

**重点内容**
- **升级体系**是本章核心：整包升级、**差分升级**（仅传输差异部分）、OTA 远程升级、本地化部署工具升级、WEB 在线升级、萤石云平台升级、APP 包在线升级（HEOP 场景）、子设备批量升级，共 8 类路径，均遵循「预下载升级包 → 下发升级 → 轮询 `GET /ISAPI/System/upgradeStatus` 进度 → 重启生效」的时序。
- **HEOP（海康嵌入式开放平台）**：支持第三方 APP/算法引擎的安装、运行、权限控制与升级，配合「APP 自定义&自解析事件」实现 APP 事件自定义上报。

- **运维工具**：操作日志查询/导出、运行日志、设备抓包（远程 tcpdump 类排障）、硬件资产管理、功能运行互斥（如某些智能功能不可同时开启）。

**摘要**：本章覆盖设备生命周期管理类功能：以 8 条升级路径（差分/OTA/WEB/平台/APP 包/子设备批量等）为主干，外加 HEOP 开放平台、串口透传、IO 输入输出、用户与权限、日志与抓包运维、时间校时等设备通用能力，是设备侧集成的基础章节。

## 第 6 章　网络配置

**索引**：HTTP 事件报文模板、IP 地址过滤、ISUP 多中心管理、码流流量控制、热点服务信息管理、Syslog 协议接入、网络流量监控、WiFi 网络管理、武汉云存储协议接入、移动网络管理、自定义 HTTP 调用。

**重点内容**
- **ISUP 多中心管理**：设备可同时注册到多个中心平台，各中心独立配置注册参数与状态查询。
- **安全过滤**：IP 地址过滤（黑白名单）控制哪些主机可访问设备。
- **对接类协议**：Syslog 接入（日志外发）、武汉云存储协议接入、自定义 HTTP 调用（设备作为 HTTP 客户端回调第三方）、HTTP 事件报文模板（自定义事件推送报文格式）。
- **链路管理**：WiFi、移动网络（4G）、热点的配置与状态；码流流量控制与网络流量监控用于带宽治理。

**摘要**：本章讲设备的网络侧集成：多中心 ISUP 注册、IP 过滤等访问控制、WiFi/4G/热点链路管理、Syslog/云存储/自定义 HTTP 三类外发对接，以及流量控制与监控，核心是让设备在复杂网络环境下安全、可控地接入平台。

**摘要**：本章覆盖安装阶段两件事：镜头清洁/雨刷的远程运维控制，以及相机架设参数的标定与倾斜变动检测报警，保障智能检测算法在正确架设条件下运行。

## 第 8 章　信息安全

**索引**：安全加固配置（含非法登录锁定、登录/预览最大连接数）、证书配置（CA 证书、设备证书、证书请求、证书失效联动）。

**重点内容**
- **安全加固**：安全基线开关、**非法登录锁定**（连续失败锁定账号）、登录与预览最大连接数限制。
- **证书体系**：CA 证书导入、设备证书签发（CSR 证书请求流程）、证书失效联动（证书过期后的行为策略），支撑 HTTPS/802.1x 等安全接入。

**摘要**：本章定义设备安全两门课：一是安全加固（登录锁定、连接数限制、基线开关），二是 PKI 证书全生命周期（CA/设备证书/CSR/失效联动），满足等保与海外安全合规要求。

## 第 9 章　视频通用

**索引**（23 个功能点）：场景变更、定时抓拍、定时抓图任务、多通道全景图像拼接、多限位补光、可视域管理、可视域目标信息叠加、OSD、取流路数、视频套餐配置、视频通道管理、视频隐私遮蔽、视频遮盖、视频质量检测、手动抓拍事件、手动抓拍图片（二进制/URL）、数字通道手动抓拍（二进制/URL）、TOF 遮盖、虚焦侦测、移动侦测、预置点专用聚焦。

**重点内容**
- **抓图两条通道**：二进制直返（`GET .../picture` 返回 JPEG 流）与 URL 方式（先抓拍存设备、返回 URI 再下载，下载需认证或带 token）。
- **移动侦测**：网格化区域（22×18 网格按位图编码为 16 进制串）+ 灵敏度 + 布防时间 + 联动方式，支持目标识别关联（VMD 事件后 10s 内关联人体比对事件，以 UUID 关联去重）。
- **隐私遮蔽 vs 视频遮盖**：隐私遮蔽为局部区域打码（矩形/多边形），视频遮盖为整画面遮蔽并可配布防时间与联动。
- **视频质量检测**：遮挡、偏色、清晰度异常、花屏、冻结、抖动、亮度异常、噪点等 15 类诊断项，各自独立布防与联动。
- **多通道全景拼接 / 多限位补光**：全景相机的多 sensor 拼接标定、分区域补光策略。

**摘要**：本章是视频业务的核心集成指南：取流之外的画面层功能——抓图（二进制/URL 两式）、OSD 与智能信息叠加、移动侦测（网格位图区域 + 事件关联）、隐私遮蔽/视频遮盖、15 类视频质量诊断、全景拼接与补光策略，均按「能力探测 → 参数配置 → 布防 → 联动 → 事件接收」五步法集成。

## 第 10 章　录像管理

**索引**：AcuSearch 搜图、按目标类型检测录像、查询录像&图片、查询事件录像、定时录像、课程录像发布（云存储）、录像浓缩、设备内部（图片）文件转存上云、手动录像、硬盘管理、自定义云存储 URL 适配、转码码流压缩。

**重点内容**
- **录像检索**：`POST /ISAPI/ContentMgmt/search` 按通道+时间段查询，支持月历查询与事件录像过滤（recordType 可细到 `recordType.meta.../xxx` 元数据级）；返回 playbackURI 供回放/下载。
- **AcuSearch / 目标建模**：基于大模型的以文搜图——设备对关键帧建模生成目标 ID 与特征，支持事后按目标类型检索录像。
- **存储介质**：硬盘管理（状态枚举：正常/异常/未格式化/读写锁等）、EMMC 寿命监控、配额管理、NAS 网盘、云存储（图片/音视频对象存储与流式存储两种 protocolType）。
- **定时录像计划**：按计划模板 + 事件类型触发（移动侦测、越界等数十种 eventType 均可作为录像触发源）；EMMC 作录像盘时定时录像有寿命风险提示。

**摘要**：本章覆盖录像全链路：定时/手动/事件触发三类录像计划，按通道、时间、事件类型、目标特征（AcuSearch）多维检索，本地硬盘/EMMC/NAS/云存储四类介质管理，以及录像浓缩、转码压缩、文件转存上云等增值能力。

## 第 12 章　客流统计

**索引**：客流统计功能接入、实时/周期统计数据获取、统计报表、事件上报、特殊说明等 6 小节。

**重点内容**
- 客流量统计（PeopleCounting）以**事件 + 周期统计**双通道输出：进入/离开人数实时事件，周期统计数据接口查询。
- 支持热度图（heatmap）类衍生数据；客流事件 eventType 为 `PeopleCounting`、`PeopleNumChange`（人数异常）。

**摘要**：本章讲客流相机的集成：通过事件流获取实时进出人数，通过统计接口获取周期报表，配合人数异常事件做阈值告警，本章以事件与数据定义为主，配置接口较少。

## 第 13 章　车辆识别

**索引**：车牌信息、机动车识别、终端交通事件数据查询（另承接 12.7 特殊说明）。

**重点内容**
- **ANPR 事件**：车牌识别结果（车牌号、颜色、车型、品牌、车身颜色等属性）随事件上报，图片以 multipart 表单或 URL 携带。
- **名单比对**：授权名单/非授权名单（黑白名单）比对与布防，normal/whitelist/blacklist 三种取证模式决定是否上报违章。
- **违章取证**：违停、逆行、压线等违章类型词典可配（违法词典参数），违章抓拍布防仅对 ANPR 的 illegalInfo 生效。
- **终端交通事件数据查询**：设备本地缓存的交通事件可分页检索。

**摘要**：本章讲车辆识别集成：车牌识别事件（属性+图片）、黑白名单比对布防、违章类型词典与违章取证上报、以及设备端交通事件的本地查询，是出入口与卡口场景的核心章节。

## 第 14 章　异常行为检测

**索引**：快速移动、徘徊侦测、人员聚集、物品拿取、物品遗留等行为的检测配置与事件接入。

**重点内容**
- 每种行为统一模式：**布防时间 → 检测参数（灵敏度/持续时间）→ 检测区域（矩形规则框，多区域）→ 联动方式 → 事件上报**（eventType 如 group、parking 之外的行为类）。
- 区域坐标语义注意：数据中心异常行为检测服务器 3.2.5~4.1.0 版本事件中的区域坐标按目标框返回，4.2.0 起通过 `isRegionCoordinatesListChange` 区分规则框/目标框——集成方需做版本兼容。

**摘要**：本章覆盖五类经典异常行为（快速移动、徘徊、聚集、物品拿取/遗留）的规则配置与事件接入，接口形态高度同构，重点在区域坐标在前后端/服务器版本间的语义差异。

## 第 15 章　人脸抓拍

**索引**：人脸侦测、人脸抓拍（含建模与事件上报）。

**重点内容**
- **抓拍规则**：检测区域、灵敏度、最佳抓拍（目标离开后选评分最佳图建模）vs 实时抓拍。
- **人脸建模**：设备端建库存储，支持建模开关与覆盖策略；建模失败按下一时间段重选。
- **事件上报**：multipart 表单携带人脸图+背景大图；新增**抓拍质量评分**（低/中/高，对人眼、肩宽等统一标准评分）区别于抓拍内相对评分；`activePostCount` 区分同一触发源。
- 人脸靠近事件、人车核验位置上报等扩展事件。

**摘要**：本章讲人脸抓拍机的集成：抓拍规则与布防、设备端人脸建模库、抓拍事件的图片与评分上报（表单/URL 两种携带方式），以及质量评分新机制与事件关联字段（UUID/activePostCount）。

## 第 16 章　道路交通检测

**索引**：交通道路停车侦测、运动目标转向检测（电警转向事件）、机动车流量统计与行人预警。

**重点内容**
- 停车侦测沿用「布防-规则-区域-联动」模式，事件标识 `parking`。
- **电警转向事件**：车辆到达/通过停车线时间、车道行车方向等电警数据上报。
- **行人预警**：检测行人后联动激光灯/预警屏/预警灯（射频联动对侧预警桩），并可配置速度单位与超速阈值显示；支持推荐值获取（`parameterType=recommendation`）。

**摘要**：本章面向道路场景：停车检测、电警转向事件、车流量统计参数采集与行人预警联动（激光/屏幕/灯）四类功能的配置与事件接入。

## 第 17 章　周界入侵检测

**索引**：进入区域、离开区域、区域入侵（含雷达区域入侵）、越界侦测等周界规则。

**重点内容**
- 周界四规则（进入/离开/入侵/越界）同构：布防计划 → 联动（含**语音联动**，audioID 对应内置警示语音）→ 侦测规则（目标类型 detectionTarget：人/车/皮带姿态/车内人员等细分）→ 区域（多边形规则框）→ 事件。
- **智能复核**：枪球联动场景下球机二次复核降低误报，事件带复核标记。
- 报警资源携带：事件报文中 resourcesContentType=url 时按 URI 下载图片（需认证或 token；`/pic` 前缀为武汉云存储 URI），binary 时与 Content-ID 对应。
- 雷达通道的雷达区域入侵布防为独立接口组。

**摘要**：本章是智能周界的核心：四类入侵规则的统一配置范式、人/车等检测目标细分、枪球复核降误报、声光语音联动，以及事件图片资源的 URL/二进制两种获取方式与认证要求。

## 第 18 章　高空抛物检测

**索引**：高空抛物检测（布防/联动/规则/屏蔽区域/结果查询/事件上报）。

**重点内容**
- 规则含置信度阈值过滤；支持**事件屏蔽区域**排除误报源。
- 事件携带**小视频**（记录抛出至抛物线完成，约 5M 内，云存储流模式上传，无云时走二进制；不受码流编码与隐私遮蔽影响）与叠加运动轨迹的检测图。
- 检测结果支持异步检索（searchID 保持一致轮询进度）。

**摘要**：本章讲高空抛物专用功能：规则置信度过滤、屏蔽区域、报警结果异步查询，以及事件小视频与轨迹叠加图的上报方式（云存储/二进制两路）。

## 第 19 章　算法调度

- 取流源多样：实时流、图片、轮询、历史流、接入设备事件二次分析、本地录像等。

**摘要**：本章概述 AIOP 算法调度流程：导入算法包、绑定引擎、下发视频任务并选择取流方式，实现模型在设备端的按需加载与分析，是智能算法类集成的前置说明。

## 第 20 章　视频识别

**摘要**：本章为视频识别类杂项集成：电梯场景的传感器校准与楼层叠加/统计、周界算法独立升级、以及教育等行业的专用行为检测，功能点多但各自独立。

## 第 21 章　体育运动

**摘要**：本章讲音频输出联动：内置/自定义语音库管理、事件联动播报（含 TTS 与多文件顺序播放、优先级），是声光警戒方案的声音侧集成说明。
